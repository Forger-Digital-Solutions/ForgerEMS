# Forger Digital Solutions — Support Development Content Pack

## Main campaign page

### Help build free, privacy-conscious software for technicians, small businesses, and everyday users.

Forger Digital Solutions builds practical Windows tools that respect local control, explain their limits, and help people make informed maintenance and recovery decisions. **ForgerEMS** is the flagship currently available public preview: a Windows technician-assist application for safer USB toolkit workflows, local diagnostics, driver guidance, and local-first assistance.

The project is real and actively developed: the repository includes the WPF application, installer definition, portable package flow, public-preview documentation, release validation scripts, and automated tests. Reported validation results are published as local results; they are not a certification or independent security audit.

Donations can help sustain independent development and may support development time, test computers and storage devices, replacement parts and test hardware, code signing, website and hosting costs, release infrastructure, accessibility improvements, documentation, compatibility testing, and security/dependency maintenance. These are intended or possible uses, not promises that every expense is active today.

### Transparency, privacy, and independence

Funding updates may be published as practical information becomes available. Priorities may change with user feedback, safety work, compatibility findings, and available resources. The ForgerEMS application should not store supporter payment details; payment platforms handle payment processing. The project does not ask for cryptocurrency seed phrases, remote-access credentials, or sensitive banking credentials.

## Donation FAQ

### Is ForgerEMS free?

The current public preview is free to try. The proprietary license governs use and redistribution; see `LICENSE`.

### Is a donation required?

No. ForgerEMS remains usable without donating.

### What does my donation support?

Independent development and possible costs such as testing, documentation, accessibility, hosting, code signing, release infrastructure, and dependency maintenance.

### Does donating guarantee a feature?

No. Priorities may change, and donations do not guarantee requested features or priority support.

### Is this an investment?

No. Donations provide no equity, ownership, profit sharing, return, or repayment.

### Is ForgerEMS open source?

No. The repository’s `LICENSE` identifies ForgerEMS as proprietary software.

### Is the preview safe to use?

It has reported local validation and safety gates, but it is preview software. Review the safety documentation, back up important data, and verify removable targets. No guarantee is made.

### Does ForgerEMS collect personal data?

The repository states telemetry and crash reporting default to off, and reports stay local unless the user exports or shares them. See `docs/PRIVACY_AND_DATA_HANDLING.md`.

### Can businesses use it?

The repository does not establish a public commercial-use policy beyond the proprietary license. Owner confirmation is required before making a broader public claim.

### How can I report a bug?

Use `docs/BETA_ISSUE_REPORT_TEMPLATE.md` and the configured support contact; send only sanitized evidence.

### Can I contribute without donating?

Yes: report reproducible issues, review documentation, test on appropriate hardware, or share accurate feedback. Contribution and source-access terms require owner confirmation.

### Where can I verify downloads and checksums?

Use the release’s `CHECKSUMS.sha256` and the instructions in `docs/RELEASE_PUBLIC_PREVIEW_v1.2.4-preview.4.md`.
